## Язык программирования

Разработанный язык программирования представляет собой минималистичный диалект **Lisp (S-expressions)** с поддержкой рекурсивных функций, глобальных и локальных переменных, арифметических операций, условных ветвлений и асинхронных прерываний.

### Синтаксис
Программа состоит из S-выражений (выражений в скобках). Поддерживаются следующие конструкции:
* Присваивание: `(setq variable expression)`
* Объявление функции: `(defun name (arg1 arg2 ...) body)`
* Последовательное выполнение: `(progn expr1 expr2 ...)`
* Условное ветвление: `(if condition then_branch else_branch)`
* Работа с массивами/строками по индексу: `(aref base index)`, `(aset base index value)`
* Ввод-вывод через порты: `(in port_num)`, `(out port_num expr)`, `(print expr)`
* Прерывания: `(definterrupt name () body)`, `(ei)`, `(di)`, `(iret)`

### Семантика
* **Стратегия вычислений:** аппликативная (аргументы вычисляются перед вызовом функции).
* **Области видимости:** глобальные переменные хранятся в статической памяти данных (`symbol_table`). Локальные переменные (аргументы функций `defun`) маппятся на аппаратные регистры (`R1..R5`) и затеняют глобальные имена.
* **Типизация:** динамическая слабая (целые 32-битные числа и указатели на Pascal-строки). Все языковые конструкции являются выражениями (`statement-as-expression`).

## Организация памяти

Модель памяти процессора построена по принципу **фон Неймановской архитектуры (`neum`)**:
* Единое адресное пространство размером **4096 32-битных слов**.
* **Разделение адресного пространства:**
  * `0x0000 .. 0x03E7` (0–999): Сегмент кода (.text) — инструкции программы.
  * `0x03E8 .. 0x0BFF` (1000–3099): Сегмент статических данных (.data) — глобальные переменные и Pascal-строки (`pstr`).
  * `0x0C00 .. 0x0FFF` (3100–4095): Свободная память и Стек (.stack). Вершина стека инициализируется на адресе `4095` и растет вниз.

### Работа со структурами данных:
1. **Литералы и переменные:** числовые константы загружаются через непосредственную адресацию (`LDI`). Переменные отображаются на статические ячейки памяти данных и читаются/записываются через `LD`/`ST`.
2. **Поддержка строк (`pstr`):** статические строки хранятся в формате Pascal (первое слово — длина, далее ASCII-символы по одному на машинное слово). Выражение со строковым литералом выделяет память в сегменте `.data` и возвращает указатель (адрес начала строки).

## Система команд

Процессор реализован по принципам архитектуры **RISC**:
* Фиксированная длина команд — **32 бита (4 байта)**.
* Обработка данных выполняется **строго в регистрах**.
* Доступ к памяти — отдельными командами `LD` и `ST`.
* Регистровый файл: 16 регистров (`R0` – `R15`), где `R0` аппаратно заземлен на ноль, а `PC`, `SP`, `CR` и `PS` вынесены как отдельные аппаратные регистры.
* **Система прерываний (`trap` + `port`):** ввод-вывод осуществляется через порты `0` (вход) и `1` (выход). Прерывания обрабатываются аппаратно: при наличии активного запроса от внешнего устройства (`dev_signal = 1`) и разрешенных прерываниях (`IE = 1`), процессор сохраняет `PC` и `PS` в стек и переходит на вектор прерывания (адрес `1`).

### Набор инструкций (32 команды)
* **Память:** `LDI`, `LD`, `ST`
* **Арифметика и АЛУ:** `ADD`, `SUB`, `MUL`, `DIV`, `MOD`, `INC`, `DEC`, `CMP`
* **Логика и сдвиги:** `AND`, `OR`, `XOR`, `NOT`, `LSL`, `LSR`
* **Ветвления:** `JMP`, `JZ`, `JNZ`, `JL`, `JGE`
* **Стек и вызовы:** `CALL`, `RET`, `PUSH`, `POP`
* **Порты и прерывания:** `IN`, `OUT`, `EI`, `DI`, `IRET`
* **Останов:** `HLT`

## Транслятор

Консольное приложение (`translator.py`) реализует двухпроходный компилятор.

**Интерфейс командной строки:**
```bash
python3 src/translator.py -i <input.lisp> -o <target.bin> [-l <listing.txt>]
```

**Этапы трансляции:**
1. **Токенизация:** разбиение текста на лексемы с сохранением строковых литералов и удалением комментариев (`;`).
2. **Парсинг (AST):** рекурсивный спуск с построением вложенного дерева выражений.
3. **Семантический анализ:** проверка зарезервированных имен, арности функций, валидация портов и лимита регистров.
4. **Генерация кода:** рекурсивный обход AST (post-order), динамическое выделение регистров `R1..R10` и трансляция в RISC-инструкции.
5. **Компоновка (Linker):** двухпроходное разрешение символических меток в числовые адреса памяти.
6. **Сериализация:** запись 32-битного дампа памяти в настоящий бинарный файл через `struct.pack` и генерация отладочного листинга `<address> - <HEXCODE> - <mnemonic>`.

## Модель процессора

Консольное приложение (`machine.py`) реализует потактовый симулятор процессора с жесткой логикой управления (Hardwired Control Unit — `hw`) и кэш-памятью (`cache`).

**Интерфейс командной строки:**
```bash
python3 src/machine.py -c <code.bin> [-i <input.txt>] [-t <max_ticks>]
```

### DataPath (Тракт данных)
* Содержит регистровый файл (`R0..R15`), регистр состояния (`PS` / `NZCV`), указатель стека (`SP`), счетчик команд (`PC`) и регистр команд (`CR`).
* АЛУ выполняет арифметические и логические операции, обновляя флаги состояния в регистре `PS`.

### ControlUnit (Устройство управления)
* Реализует цикл выполнения инструкции: **Fetch $\rightarrow$ Decode $\rightarrow$ Execute**.
* Поддерживает тактовый генератор (`tick`).
* **Кэш-память (`cache`):** Прослойка между процессором и памятью (Direct-Mapped кэш на 8 строк). Задержка при попадании (Hit) составляет **1 такт**, при промахе (Miss) — **10 тактов** с переходом процессора в режим ожидания (Stall).
* **Прерывания (`trap`):** обрабатывает внешнее расписание ввода, поднимая аппаратный флаг `dev_signal` и сохраняя контекст в стек.
